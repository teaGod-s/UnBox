# 播放设置与点播自动化设计

日期：2026-09-11

## 1. 背景

当前点播详情页支持手动选集和手动切换线路，但播放结束、线路故障和下一集准备都需要用户操作。本功能在设置页增加三个可持久化的播放选项，并把 Web 播放器与独立 mpv 播放器的状态统一交给点播播放会话协调。

## 2. 目标

新增“播放设置”分类，提供三个开关：

- 自动切集：当前线路有下一集且当前集自然结束时自动播放下一集。
- 自动换源：当前集明确报错，或连续 30 秒未起播/持续缓冲时，按详情页线路顺序尝试其他线路。
- 预载下一集：Web 播放时预载下一集；mpv 播放时只做可取消的后台网络预热。

三个选项首次安装默认关闭，并通过现有 `ShellService + store.kv` 持久化。

## 3. 已确认的行为

### 3.1 自动切集

- 只使用当前线路的剧集数组顺序。
- 当前线路没有下一集时停止，不自动寻找其他线路。
- 自动切集触发后，新的当前集必须在剧集列表中高亮。
- 手动播放某一集时也更新当前集状态和播放记录。

### 3.2 自动换源

- 触发条件：
  - 播放器明确报告错误时立即触发；或
  - 连续 30 秒没有进入播放状态；或
  - 播放中连续缓冲 30 秒。
- 线路按详情页 `Sources` 的顺序尝试，每条其他线路最多一次；全部失败后停止并展示错误。
- 当前线路不重复尝试。
- 目标线路优先匹配与当前集名称相同的剧集；找不到同名剧集时跳过该线路，不跳到其他集。
- 切换线路时使用当前已知播放进度续播。
- 手动切换线路与自动换源使用同一条切换流程：立即播放目标线路的同名当前集、续接进度、更新 `activeSource` 和当前集高亮。
- 线路切换、自动切集和旧播放请求都必须受播放 token 保护，旧会话不能覆盖新会话状态。

### 3.3 预载下一集

- 只有当前线路存在下一集时才预载。
- Web：使用独立、隐藏、可取消的预加载媒体元素获取下一集资源；预载元素不得接管当前播放元素。
- mpv：不创建第二个 mpv 实例、不调用共享播放器的 `Load`；后台解析下一集并执行轻量网络预热，任务可在切集、换源或停止时取消。
- 预载失败、超时或被取消不得改变当前集的播放状态、进度、错误状态或线路。
- 当前集结束或用户手动切集时，预载任务必须清理。

## 4. 设置持久化

后端新增聚合设置模型：

```text
PlaybackSettings {
  AutoNext: bool
  AutoSwitchSource: bool
  PreloadNext: bool
}
```

使用三个独立 KV 键保存布尔值：`playback.autoNext`、`playback.autoSwitchSource`、`playback.preloadNext`。读取缺失、非法或数据库不可用时回退为全部关闭。设置接口必须在输入非法时保持关闭默认，不影响应用启动。

前端启动时读取设置；设置页打开时显示当前值；用户切换开关后立即更新界面并持久化。持久化失败时保留当前运行时值并通过现有错误处理展示错误。

## 5. 播放状态与事件

### 5.1 Web 播放

`PlaybackView` 增加标准化事件：

- `playing`：进入实际播放状态，清除“未起播”计时。
- `waiting` / `stalled`：进入缓冲状态，启动或继续缓冲计时。
- `canplay`：可继续播放，清除缓冲计时。
- `error`：明确播放错误，向点播会话上报。
- `ended`：自然结束，触发自动切集（如已开启）。
- `progress`：持续更新当前进度，供续播和切源使用。

组件只报告事件，不决定切集或换源；决策统一在 `App.vue` 的点播播放会话中完成。

### 5.2 mpv 播放

后端将共享播放器事件桥接为 Wails 事件，并携带当前播放 token 和事件类型。至少包含：`playing`、`buffering`、`error`、`ended`、`position`。mpv 事件桥接必须解决播放器事件通道只有一个消费者的问题，不能让故障切换包装器吞掉前端需要的终端事件。

前端只接受 token 与当前点播会话一致的事件。mpv 的位置事件用于记录进度和线路切换续播；事件桥接异常不应阻止手动播放。

## 6. 线路与剧集匹配

播放会话记录当前站点、线路、剧集 ID、剧集名称、当前进度、已尝试线路集合和会话 token。

- 线路切换先按目标 `Source` 过滤剧集。
- 首选 `Name` 去除首尾空白后的完全匹配。
- 找不到匹配时，该线路视为不可用并继续尝试下一条线路；不使用目标线路的第一集替代当前集。
- 成功切换后更新 `activeSource`、`currentEpisodeID`、当前集名称和历史记录。
- 由于 `EpisodeInfo.ID` 可能随线路变化，不能只用 ID 判断同一集。

## 7. 取消与错误隔离

- 每次点播播放、自动换源、手动换源、自动切集和预载都有会话/任务代际。
- 新任务开始时取消旧预载；切页、返回列表、停止播放时取消所有点播任务。
- 自动换源期间用户手动选择集数或线路时，自动任务失效，不得回写用户的新选择。
- 所有线路尝试失败后，保留最后一次错误，设置播放状态为错误，并停止自动重试。
- 预载任务的所有错误只记录调试日志，不冒泡为当前集错误。

## 8. 设置页 UI

在现有设置页新增“播放设置”分类，沿用“个性化”分类的面板、边框、主题变量和间距。每项采用主题兼容的开关行，显示名称和当前开/关状态；不新增独立配色。建议文案：

- 自动切集
- 自动换源
- 预载下一集

可在开关旁显示一行简短说明，但不改变设置页现有密度。

## 9. 测试策略

### 前端

- 设置值缺失或非法时归一化为全部关闭。
- 开关切换调用持久化接口并保持界面状态。
- 自动切集只选择当前线路数组的下一集；无下一集不动作。
- 同名剧集线路匹配成功时更新线路、集数和续播进度；无同名集时跳过线路。
- 明确错误立即换源；30 秒未起播/持续缓冲触发换源；正常播放不会误触发。
- 线路尝试集合防止重复和循环；旧 token 事件不会影响新会话。
- Web 预载任务可取消且失败不改变当前播放状态。

### Go

- 设置 KV 的默认、读取、非法值和跨服务实例持久化。
- 播放器事件桥接的 token 过滤和终端事件送达。
- 预热任务取消后不调用共享播放器的 `Load`。
- 现有播放、故障切换和服务测试保持通过。

## 10. 非目标

- 不改变直播播放行为。
- 不改变本地媒体库的播放策略。
- 不改变点播接口的剧集排序和线路排序。
- 不在预载阶段创建第二个可见播放器或抢占共享 mpv 窗口。
- 不在自动换源失败后无限循环重试。
