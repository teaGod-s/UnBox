# 捐助榜单设计

日期：2026-09-20

## 1. 背景与目标

在设置页展示捐助人榜单：头像 + 昵称，按累计捐助金额从高到低排列，感谢支持者。

## 2. 数据来源（方案 B3）

- 榜单数据由**离线导出脚本**生成 JSON，发布在仓库 raw 地址（常量可改）：
  `https://raw.githubusercontent.com/teaGod-s/UnBox/master/docs/donors.json`
- **凭据不进入客户端**：爱发电 OpenAPI 需要 `user_id` + `token` 签名，这两个值只在本机通过环境变量
  （`AFDIAN_USER_ID` / `AFDIAN_TOKEN`）提供给导出脚本，不写入仓库、不编进应用。
- 应用侧：**远程拉取优先 → 写本地缓存 → 失败回退内置快照**，界面始终有内容。

## 3. JSON 结构

```json
{
  "updatedAt": "2026-09-20T12:00:00+08:00",
  "donors": [
    { "id": "u-1", "name": "张三", "avatar": "https://...", "amount": 128.0, "anonymous": false }
  ]
}
```

- `amount` 为累计金额（元），仅用于排序；**界面不展示金额**（避免攀比与隐私顾虑）。
- `anonymous` 为真时：用默认头像 + 昵称显示为「热心网友」，不展示 ID 与头像。
- `donors` 由脚本按 `amount` 降序输出（金额相同按昵称稳定排序）；后端归一化时保持该
  排序，前端只做字段归一化并信任后端顺序，因为公开给前端的结构不包含金额。

## 4. 导出脚本

- 位置：`cmd/unbox-donors`（纯 Go 标准库，与其它命令一致）。
- 用法：`AFDIAN_USER_ID=xxx AFDIAN_TOKEN=yyy go run ./cmd/unbox-donors > docs/donors.json`
- 职责：调用爱发电 `POST /api/open/query-sponsor`（分页拉全量）→ 归一化为上面的结构 →
  按金额降序输出。缺环境变量时给出明确报错并退出非零。
- 脚本只在本地/手动使用，不参与应用构建与 CI 发布。

## 5. 应用侧实现

- 后端（`internal/shell`）：`GetDonationLeaderboard() DonationLeaderboard`：
  - 缓存命中（默认 6 小时）直接返回；
  - 否则拉取远端 JSON，成功则写 `store.kv`（键 `donations.cache`）并返回；
  - 拉取/解析失败时返回缓存；无缓存时返回内置快照；**任何失败都不弹错误**。
- 内置快照：`internal/shell` 内嵌一份随榜单刷新同步的 `donors.json`（`go:embed`），保证离线可用。
- 前端：设置页「关于」区域新增「捐助榜单」按钮 → 沿用现有 `settings-overlay` +
  `settings-panel` 主题样式弹窗；列表项为头像（圆形，加载失败回退默认头像）+ 昵称；
  底部小字标注「数据更新于 <updatedAt>」。
- **捐助入口位置调整**：设置页「关于」区原有的「捐助」按钮**移入榜单弹窗底部**作为行动号召，
  点击仍打开爱发电链接（`DONATE_URL`）；设置页不再单独保留捐助按钮，避免两个入口并存。

## 6. 边界与失败处理

- 网络不可用 / JSON 非法 / 字段缺失：逐级回退（远端 → 缓存 → 内置），不阻塞设置页。
- 头像加载失败：隐藏破图，显示默认占位（不展示碎图）。
- 榜单为空（例如尚未有人捐助）：显示「还没有捐助记录，感谢每一份支持」。
- 不展示金额、不展示真实姓名以外的个人信息；`anonymous` 的条目完全不显示 ID 与头像。
- 该功能不发起任何自动轮询，只在用户打开榜单时按缓存策略刷新。

## 7. 测试策略

- **Go**：缓存命中不重复请求；拉取失败回退缓存；无缓存回退内置快照；非法 JSON 不 panic；
  排序稳定（金额相同按昵称）；`anonymous` 归一化。
- **前端**：登录项渲染（头像/昵称/更新时间）、空列表文案、头像加载失败回退默认头像。
- 提交前：`gofmt`、`go test ./... -count=1`、`go vet ./...`、`CGO_ENABLED=1 go build ./...`、
  前端 `npm test -- --run` 与 `npm run build`。

## 8. 非目标

- 不在客户端内置爱发电 token，也不由客户端直连爱发电 API。
- 不做实时榜单、不做金额明细展示、不做捐助排行榜的历史变化。
- 不新增独立页面；入口收敛在设置页弹窗内。
- 位置调整只涉及「捐助」按钮，「检查更新 / 关于我们 / 免责条款 / 开源库 / 源码」保持原位。
