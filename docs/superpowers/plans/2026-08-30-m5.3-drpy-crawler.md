# M5.3 dr_py 方言适配 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让独立 dr_py（`var rule`）`.js` 站点在 goja 内本地运行浏览/搜索/详情/播放。

**Architecture:** 复用 M5.1 的 `req`/`rule`/`helpers`，新增 Go 侧 dr_py 规则解释器（`class_parse`/`json:`/`js:`/`lazy`/gbk），`js:`/`lazy` 片段用 goja 跑。不捆绑 drpy.min.js。

**Tech Stack:** Go 1.26、goja、goquery、`golang.org/x/text`（GBK）。

**Spec:** `docs/superpowers/specs/2026-08-30-unbox-m5.3-drpy-design.md`

## Global Constraints

- 纯 Go、无 CGO、无 Node 依赖（「安装即用」）。
- goja `v0.0.0-20260826204918-8f1c0696a37b`、goquery `v1.13.0` 已钉死。
- 合规：真实 dr_py 脚本/地址不进 git；fixture 用 `example.com` 脱敏。
- 不破坏 M5.1 的 FongMi js0 路径（`export default` 分发）。
- 错误信息用中文，风格与现有代码一致。

- [ ] **Step 1: 写失败测试**

```go
func TestParseClasses(t *testing.T) {
    html := `<ul><li><a href="/list/movie.html">电影</a></li><li><a href="/list/tv.html">电视剧</a></li></ul>`
    cls, err := parseClasses(html, `li&&a&&Text;li&&a&&Text;li&&a&&href;/(\w+)\.html`)
    if err != nil || len(cls) != 2 || cls[0].TypeID != "movie" || cls[0].TypeName != "电影" {

```

- [ ] **Step 2: 运行确认失败**
