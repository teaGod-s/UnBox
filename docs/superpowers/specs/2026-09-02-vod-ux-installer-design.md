# 点播、直播与安装体验增量设计

**日期：** 2026-09-02  
**基线：** `docs/superpowers/specs/2026-09-01-vod-playback-navigation-design.md`

## 目标

在既有点播播放隔离、返回导航和 36 集分页基础上，修复播放器尺寸抖动、统一顶部导航、补齐搜索历史与点播收藏、增强直播切台反馈和频道展示，并降低 Windows 更新安装成本。

## 设计

### 导航与持久化

顶部导航使用 `home`、`vod`、`live`、`search`、`favorites`、`settings` 六种模式。点播列表和详情不再渲染搜索表单；搜索模式独立维护查询、进度、结果缓存和历史词。SQLite 增加 `vod_search_history`、`vod_favorites`，并为 `vod_history` 提供删除 API。点播收藏以 `site+vod_id` 去重，详情简介面板显示收藏切换，收藏模式列出可播放条目。

### 播放与布局

点播播放器外层使用固定 16:9 响应式 frame，限制最大高度并隐藏媒体元素溢出的布局影响；控制条、线路和集数列表留在 frame 之外的滚动容器。直播和点播切台均先进入准备状态，失败时清除旧播放计划并显示错误。集数分页、左右箭头和进度信息采用同一 flex 对齐规则。直播频道名使用省略号，悬浮时在自身裁剪区域内滚动。

支持 Web 播放的 Windows/macOS 默认不弹出 mpv 安装提示；仅在 Web 播放明确失败并触发 mpv 回退时，才显示安装/回退提示。收藏列表和详情面板均提供逐条删除/取消收藏操作。

### 分类缓存

ShellService 对每个点播站点缓存分类结果 5 秒；读取缓存前校验过期时间，导入/删除源时清除对应站点缓存。切换线路或站点后先刷新分类，再刷新列表，失败时保留空分类和可见错误。

### Windows 安装器

NSIS 从卸载注册表的 `InstallLocation` 读取上次目录，并在写卸载信息时保存当前目录。`.onInit` 检测带有 UnBox 标题的窗口，提示用户关闭后重试；无法关闭时允许退出安装，不强制终止用户进程。

### 依赖同步

审计 `go.mod` 和 `frontend/package.json` 的可更新版本，只采用官方发布信息和兼容的 patch/minor 更新；Wails 固定 `3.0.0-beta.9`，不做跨大版本升级。设置页开源库清单与实际锁定版本保持一致。

## 测试策略

- Store 测试覆盖搜索词 upsert/排序/单条删除、点播收藏 CRUD、观看记录删除。
- ShellService 测试覆盖分类缓存命中、TTL 过期和源变更失效。
- 前端测试覆盖顶部模式、历史删除、收藏切换、搜索结果返回和播放器错误状态；`vue-tsc` 负责类型检查。
- NSIS 做脚本静态检查，Windows 原生构建由 CI/Windows 主机验收。
- 最终执行 `mise run test`、`mise run build:linux`（或等价 CGO 构建）、`go vet ./...`、前端生产构建。

## 非目标

- 不改变 TVBox/Drpy 解析协议和线路探测算法。
- 不强制杀死正在运行的 UnBox 进程。
- 不升级 Wails beta.9，也不引入新的前端 UI 框架。
